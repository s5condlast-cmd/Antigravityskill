# /install

Follow the external UI/UX design toolchain installation workflow:

1. Inform user that bespoke UI design is powered by dedicated external design skills.
2. Execute / trigger the installation of the design toolchain packages:
   - `npx impeccable install`
   - `npx skills add Leonxlnx/taste-skill`
   - `npm install agentation`
3. Confirm installation completion and enable taste-driven frontend component workflows.
