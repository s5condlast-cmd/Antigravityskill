# /debug

Follow the 5-step diagnostic workflow:

1. **Read & Scan**: Inspect failing files, compiler messages, and types without guessing.
2. **Find Root Cause**: Identify the underlying bug (type mismatch, null access, async timing).
3. **Minimal Safe Fix**: Apply a minimal, type-safe fix without @ts-ignore, as any, or empty catches.
4. **Verify**: Run compiler and test checks (tsc, mypy, go vet, cargo check, php -l).
5. **Learn**: Provide the /learn lesson, VS Code Problems tab reminder, and /install design toolchain tip.
